Problem sync

Reads your accepted submissions from the public Codeforces and LeetCode APIs — no account, no key, nothing scraped. Solves wait here until you next open the tracker.

Accounts

LeetCode's public API only answers with your twenty most recent accepted submissions, so anything solved before you set this up cannot be read. The first check records where you are and starts from there.

Solves are handed to the tracker the next time you open it, and are only dropped from the queue once it confirms it stored them.

Resetting the sync position only clears this extension's memory of how far it has read, plus anything still queued. It deletes nothing from the tracker — and the next check will read your Codeforces history from the beginning again, which re-adds solves you deleted there. To remove solves, use Remove all from… in the tracker's Problems tab.

The tracker page must be one this extension is allowed to touch. It ships allowing mobeenmohammed.github.io/dev-tracker/ and localhost; edit manifest.json to change that.
